## Scenario 1: Website Issue - Web Service Running

### Background

From: Loyd Jenkins [Customer]  
Subject: Website Issue

Hi,

When I tried to connect to the website, the web page does not show anything. How can I find out if the web service is running?

Thanks,

Loyd Jenkins [Customer]

### Task

Rate the effectiveness of each possible solution.

Instruction note shown in screenshots:

Please disregard any spacing in the code marked between these symbols: `< >`.

For example, if code reads as `< process-id >`, please read it as `<process-id>`.

### Questions

#### Question 1 of 5

Access the server, log every call, and read the log file.

#### Question 2 of 5

From a Linux box that you have access to, run the following command: `telnet <host> <port>`, where host is the service host, and port is what the web page port is supposed to be.

#### Question 3 of 5

Log in to the host as root and run the command `systemctl status <service>` to display the status of the service.

#### Question 4 of 5

Check the system logs looking for exceptions generated by the service.

#### Question 5 of 5

Log in to the host as root and run `ps -ef`, then look for the service name to see if it is running.
